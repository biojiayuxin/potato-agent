# DL101 试剂配制与用量核算

## 试剂盒组成与配液前准备

DL101-01 标称规格为 100 次检测反应。各组分如下。

| 组分 | 包装量 | 用途 |
| --- | --- | --- |
| 5× Cell Lysis Buffer | 10 mL | 配制 1× 裂解液 |
| Reaction Buffer II (Luciferase) | 10 mL | 复溶 Firefly 冻干底物 |
| Luciferase Substrate (Lyophilized) | 1 瓶 | 配制 Firefly 检测试剂 |
| Stop & Reaction Buffer | 10 mL | 配制 Renilla 工作液，并抑制前一步 Firefly 反应 |
| Renilla Substrate | 200 μL | 已溶于无水乙醇的 Renilla 底物原液 |

配液前备好 ddH₂O、冰浴、适量程移液器及吸头、避光配液管和分装管。核对样本数、复孔和对照，标记试剂名称、配制日期及分装量。需要恢复 Renilla 底物原液体积时，另备无水乙醇；首次检查原液需使用微量离心机短暂离心。

## 1× Cell Lysis Buffer

每次使用前，将 5× Cell Lysis Buffer 与 ddH₂O 按体积比 **1:4** 混匀，所得工作液终浓度为 1×，置于冰上备用。

| 组分 | 配制 1 mL 工作液 | 配制终体积为 `V` 的工作液 |
| --- | --- | --- |
| 5× Cell Lysis Buffer | 200 μL | `V/5` |
| ddH₂O | 800 μL | `4V/5` |
| 终体积 | 1,000 μL | `V` |

每个约 200 mg 的植物组织样本使用 200–500 μL 1× 裂解液。不同样本选用体积不同时，以各样本所需体积之和计算净需求；采用相同体积 `v` 时，`n` 个样本的净需求为 `nv`。额外配液余量单列，并说明其依据。

## Firefly 检测试剂

1. 首次使用时，将该套试剂盒中的 **全部 10 mL Reaction Buffer II (Luciferase)** 加入装有 Luciferase Substrate 冻干底物的棕色避光瓶中。
2. 充分混匀使底物溶解，按每次实际使用量分装，避光保存。本文将复溶所得试剂称为 Firefly 检测试剂。
3. 检测前取所需分装量并平衡至室温，每个检测反应使用 100 μL。

采用配套整瓶缓冲液复溶，不将冻干底物直接加入检测反应，也不以裂解液或水替代配套缓冲液。说明书未提供底物质量和化学浓度，按配套组分和规定复溶体积配制。

## Renilla 工作液

1. 首次使用 Renilla Substrate 原液时，短暂离心并小心量取管内液体体积。若发现体积明显减少，按说明书用无水乙醇补足至原标示体积，再按要求保存；未取用的原包装标示量为 200 μL，已取用后的剩余原液不能每次补至 200 μL。
2. 使用时将原液暂存于冰上。按实际检测需求，将 Stop & Reaction Buffer 与 Renilla Substrate 原液按体积比 **50:1** 混匀。
3. 新鲜配制的工作液置于室温避光备用，每个检测反应加入 100 μL。原液与缓冲液混合后总体积为 51 份，不能将“50:1”解释为终体积中的 1/50 原液。

| 组分 | 配制 1,020 μL 工作液 | 配制终体积为 `V` 的工作液 |
| --- | --- | --- |
| Stop & Reaction Buffer | 1,000 μL | `50V/51` |
| Renilla Substrate 原液 | 20 μL | `V/51` |
| 终体积 | 1,020 μL | `V` |

上述示例可供 10 次检测反应使用，并余 20 μL；这 20 μL 是该示例的配液余量，不是说明书规定的统一损耗量。底物原液浓度未给出，不能据此计算其摩尔终浓度。

## 批量用量

设每个独立样本检测 `r` 个复孔，独立样本数为 `n`，另有 `c` 个对照检测反应和 `b` 个本底检测反应，则 `R = nr + c + b`。若对照已包含在 `n` 中，不重复计数；复孔数不一致时按实际孔数求和。

| 项目 | 净需求 |
| --- | --- |
| 每份样本的裂解上清 | `20r μL`，转移损耗另计 |
| Firefly 检测试剂 | `100R μL` |
| Renilla 工作液 | `100R μL` |
| 配制上述 Renilla 工作液所需 Stop & Reaction Buffer | `5,000R/51 μL` |
| 配制上述 Renilla 工作液所需 Renilla Substrate 原液 | `100R/51 μL` |
| 检测管或有效检测孔 | `R` 个；两次发光检测共用同一管或孔 |

上表按每个完整双酶检测反应均使用两种检测试剂核算；若预实验的本底检测采用其他已确定的体系，应单独列出实际用量。仅加底物的本底检测不计入样品上清需求。

若计划额外配制比例为 `f` 的余量，分别将相应检测试剂净需求乘以 `1 + f`；`f` 是根据移液损耗确定的实验安排，不是试剂盒规定值。使用带自动进样管路的仪器时，管路死体积另计。所需微小体积低于移液器可靠量程时，应扩大统一配液批量，不随意改变组分比例。

## 保存与使用温度

| 试剂或状态 | 说明书规定条件 |
| --- | --- |
| 试剂盒 | −30 至 −15 °C 保存；运输温度不高于 0 °C |
| 复溶、分装后的 Firefly 检测试剂 | 长期保存于 −85 至 −65 °C；首次复溶注意事项指定避光保存于 −70 °C，属于该范围。短期可于 −30 至 −15 °C 保存，不超过 1 个月 |
| Stop & Reaction Buffer | 长期保存于 −20 °C |
| 配制后的 1× Cell Lysis Buffer | 使用前置于冰上备用；说明书未另列稀释后保存期限 |
| Renilla Substrate 原液 | 保存遵循试剂盒条件，使用时暂存于冰上 |
| 新鲜配制的 Renilla 工作液 | 室温避光备用；说明书未给出配制后长期保存条件，不套用 Firefly 检测试剂的冻存期限 |
| 检测时的裂解上清与检测试剂 | 均平衡至室温后使用；植物组织裂解上清的保存温度与期限另按实际说明书或已验证方案确认 |

长期保存的具体时限除上述短期 1 个月外，说明书未另行给出，应同时遵循产品标签有效期。
