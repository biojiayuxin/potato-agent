# DNA 琼脂糖凝胶回收

**本技能参照天根（TIANGEN）DP219 琼脂糖凝胶 DNA 回收试剂盒（增强型），说明书版本 DP260101 设计；实际操作以用户手中试剂盒配套的说明书和瓶签为准。**

向用户给出操作、用量或排期时，开头简要说明这一参考关系。先核对实际品牌、货号和说明书版本；使用其他试剂盒时，按其说明书重新核对参数，不直接套用 DP219 的缓冲液名称、用量及条件。

## 适用范围与输入

用于从 TAE 或 TBE 琼脂糖凝胶中回收目的 DNA 条带，包括 PCR 产物电泳后切取目的条带的回收，提供准备清单、离心柱操作、分支选择和周期估算。不涵盖无凝胶的 PCR 产物纯化、核酸提取或下游反应体系。

用户询问“PCR 产物回收”时，先区分材料是已跑胶的目的条带，还是未经电泳的 PCR 反应液。前者在满足本试剂盒适用条件时使用本流程；后者需查其手中试剂盒的 PCR 产物直接纯化说明。DP260101 未提供 PCR 反应液直接上柱的操作方法，其中“回收 DNA 可用于 PCR”指下游用途，不能据此将胶块与 PE 的比例套用到 PCR 反应液。

DP219 的适用片段范围为 **100 bp–15 kb**，每个 CA5 柱的 DNA 吸附量上限为 **10 μg**；说明书列明可回收单链 DNA、双链 DNA 及环状质粒 DNA。范围外样本先核对实际试剂盒的适用条件。

按任务需要确认：试剂盒及版本、目的片段大小和类型、凝胶浓度与电泳缓冲液、各胶块重量、样本数、预计 DNA 量、下游用途、洗脱液与体积，以及设备和试剂就绪情况。未切胶时可先给准备清单，PE 用量和上柱次数待实际称重后核算。

## 分支选择与按需读取

本技能为单一离心柱方法；DP219-02（50 次）和 DP219-03（200 次）是包装规格，不改变单柱流程。给出完整操作、精确用量或时间核算前，读取 [references/protocol.md](references/protocol.md)；单步咨询只需读取相应小节。

Hermes 调用：`skill_view(name="dna-gel-extraction", file_path="references/protocol.md")`。

| 分支 | 选择依据 |
| --- | --- |
| 常规溶胶 | 片段不大于 5 kb 且凝胶浓度不大于 1.5%，采用说明书的室温溶胶条件 |
| 加热溶胶 | 片段大于 5 kb，或凝胶浓度大于 1.5%，建议 50 °C 溶胶，冷却至室温后上柱 |
| 分次上柱 | 实际溶胶液超过柱的 800 μL 容积时，同一样本分次上同一柱；不提高单柱 DNA 容量 |
| 盐敏感用途 | 平末端连接、直接测序等用途，两轮 PW 漂洗各增加静置步骤 |
| 洗脱液选择 | 常规用 TB；后续测序按本说明书用 pH 7.0–8.5 的 ddH₂O；另允许用 10 mM Tris-Cl、pH 8.0 |
| 回加洗脱，可选 | 希望提高回收量时，将首次洗脱液回加原柱再洗脱；不等同于另加一份新洗脱液 |

低回收率时按参考文件检查溶胶、结合液 pH、漂洗液状态和洗脱条件；pH 调整是条件分支，不作为所有样本的常规加液步骤。

## 实验前准备

给出完整流程或排期前，先提醒用户备齐以下项目，并单独列出就绪检查；仅回答某个步骤时提醒与该步相关的准备即可。

| 类别 | 准备要求 |
| --- | --- |
| 材料 | 已完成电泳、目的条带可定位的琼脂糖凝胶；记录样本、片段大小、胶浓度及预计 DNA 量。电泳尽量使用新鲜缓冲液，下游要求较高时按说明书优先选 TAE |
| 仪器 | 凝胶观察设备、天平、移液器和台式离心机；转子及柱/管组合需适配说明书的离心条件。加热溶胶时准备 50 °C 恒温设备；试剂有沉淀时准备 37 °C 水浴。选做检测时备好分光光度计或电泳设备 |
| 耗材 | 每个单柱样本至少 1 个干净溶胶管、1 个 CA5 柱及其 2 mL 收集管、1 个干净洗脱收集管；另备切胶器或洁净刀片、吸头、管架和标签。溶胶管需容纳胶块与 3 倍体积 PE，并留混匀空间；分管、检测和分装耗材另计 |
| 试剂 | PE、已按瓶签加入无水乙醇的 PW、所选洗脱液；PW 净需求为 1.2 mL/柱。需要 pH 排查时备 pH 检测用品及 3 M 醋酸钠（pH 5.2）；检测所需试剂按所选方法另备 |
| 就绪条件 | 确认 PW 已正确配成工作液并标记；核对试剂状态、管重/去皮记录、样本标签、转子有效容量和可用时段。提前达到所需恒温条件；使用紫外观察时尽量缩短照射，配备相应防护 |

试剂盒各组分按说明书在 15–30 °C 干燥条件下保存；若溶液有沉淀，可于 37 °C 水浴 10 min 使其溶解。PW 的乙醇添加体积必须查瓶签，不由包装中的原液体积推算。单样本及整批试剂需求按参考文件核算，额外余量单列并说明假设。

## 周期估算

主体流程可同日完成。常规单次上柱、两次普通漂洗及一次洗脱的**定时小计为 16.5–24.5 min（约 0.28–0.41 h）**，不等于完整实验周期，也不把说明书“可缩短至 12 min”的产品介绍作为完成承诺。

排期起点为材料、试剂和设备已就绪后开始切取目的条带，终点为收集 DNA 洗脱液。单批为 `n` 个单柱样本，不超过离心机的有效容量；基准按相同分支、每柱一次上样计算。详细加总见参考文件。

| 分支 | 对定时小计的影响 |
| --- | --- |
| 加热溶胶 | 溶胶仍为 5–10 min；另加降至室温所需时间，说明书未定时 |
| 分次上柱 | 每增加一轮上样增加 2.5 min，另计移液与上下机时间 |
| 盐敏感用途 | 两次漂洗各静置 2–5 min，共增加 4–10 min；单次上柱合计 20.5–34.5 min |
| 回加洗脱一次 | 增加 4 min；常规单次上柱合计 20.5–28.5 min |

切胶称重、加液、转移、离心机升降速、冷却及设备等待未计入上述小计。检测、分装和保存处理若纳入终点，另加相应时间。电泳、PW 配制、设备预热和预约在开始前安排；试剂沉淀复溶的 10 min 也单列，不隐藏在主体流程中。

按样本数、转子容量、上样轮数、温度分支和人员安排分批。同批共用的离心和孵育时间不按样本数相乘，逐管操作需计人工时间；不同批次能否并行按设备和依赖判断。不自行添加溶胶或柱上的过夜暂停点。

## 检测与保存

可用琼脂糖凝胶电泳和紫外分光光度计检测片段、浓度与纯度；取样量按实际设备和检测方案确定，说明书未给固定体积。检测参考和水洗脱对吸光比值的影响见 [references/protocol.md](references/protocol.md)。

说明书在 ddH₂O 洗脱注意事项中明确 DNA 产物应于 **−20 °C** 保存；未另列 TB 或 Tris-Cl 洗脱产物的保存时限。需要保存时按实际试剂盒说明或已确认的实验室方案执行，不将试剂盒的室温储存条件用于 DNA 产物。
