# 石蜡切片及甲苯胺蓝染色：试剂配制

乙醇浓度和液体混合比例均按体积百分浓度或体积比表示。配制前核对试剂瓶签、浓度表达方式及目标体积；甲醛母液浓度不能由 FAA 的体积配比反推。批量需求根据[流程文件](protocol.md)中的换液次数和实际工作体积计算。

## FAA 固定液

甲醛母液∶冰醋酸∶70%乙醇 = 1∶1∶18（v/v/v）。以组分体积之和为 100 mL 的名义配制量为例：

| 组分 | 母液浓度或形式 | 用量 | 配好后的含量 |
| --- | --- | --- | --- |
| 甲醛 | 甲醛水溶液，母液浓度及其标示方式待补充 | 5 mL | 占混合液名义体积的 5%；甲醛实际终浓度取决于母液 |
| 冰醋酸 | 冰醋酸试剂，纯度按瓶签记录 | 5 mL | 约 5%（v/v，按冰醋酸试剂体积计） |
| 70%乙醇 | 70%（v/v）乙醇水溶液 | 90 mL | 乙醇名义终浓度约 63%（v/v，按组分体积加和估算） |

在通风橱中先量取 70%乙醇，再缓慢加入冰醋酸和甲醛母液，轻轻混匀。按组分体积配比配制，不另加水定容，以免改变 1∶1∶18 的比例。记录配制日期及所用甲醛母液信息。

如目标名义配制量为 `V mL`，三者分别取 `V/20`、`V/20` 和 `18V/20 mL`。甲醛母液若以质量/体积浓度标示，其名义终浓度可按 20 倍稀释估算；若以质量分数标示，换算质量/体积终浓度还需母液密度。未确认母液前，不将该配方写作“终浓度 5%甲醛”。

## 梯度乙醇

下表以 100%乙醇为母液、每种工作液终体积为 100 mL 计算。

| 工作液 | 100%乙醇用量 | 水的加入方式 | 主要用途 |
| --- | --- | --- | --- |
| 50%乙醇 | 50 mL | 加水至终体积 100 mL | 固定后脱水 |
| 70%乙醇 | 70 mL | 加水至终体积 100 mL | FAA 配制及固定后脱水 |
| 85%乙醇 | 85 mL | 加水至终体积 100 mL | 固定后脱水 |
| 95%乙醇 | 95 mL | 加水至终体积 100 mL | 固定后脱水及染色后分化 |
| 100%乙醇 | 100 mL | 不加水 | 固定后脱水、透明过渡液配制及染色后脱水 |

量取乙醇，加入部分水混匀，待温度恢复至量器适用温度后定容。终体积 100 mL 不等于将表中乙醇与两者体积差对应的水直接相加；乙醇与水混合会产生体积变化。

采用其他已知体积浓度的乙醇母液时，按 `C母 × V母 = C终 × V终` 计算，加水至终体积。母液浓度须不低于目标浓度；100%乙醇使用合格无水乙醇，不由低浓度乙醇稀释获得。复水所需各级乙醇按确认后的复水程序另行计量。

## 乙醇–二甲苯过渡透明液

以无水乙醇和纯二甲苯配制，各配方组分体积之和为 100 mL。这里的无水乙醇用于承接脱水末级的 100%乙醇，不使用含水的低浓度乙醇替代。

| 乙醇∶二甲苯（v/v） | 无水乙醇 | 二甲苯 | 名义体积分数 |
| --- | --- | --- | --- |
| 3∶1 | 75 mL | 25 mL | 乙醇 75%，二甲苯 25% |
| 1∶1 | 50 mL | 50 mL | 乙醇 50%，二甲苯 50% |
| 1∶3 | 25 mL | 75 mL | 乙醇 25%，二甲苯 75% |

于通风橱中按比例量取两组分，混匀后分装于耐溶剂容器中。不加水，不另行定容。纯二甲苯直接分装使用，组织透明需连续处理 3 次，染色后透明需使用 2 缸新鲜二甲苯，脱蜡用量另计。

## 甲苯胺蓝商品工作液

采用北京索莱宝科技有限公司（Solarbio）的商品工作液，直接用于染色，无需自行配制或稀释。

| 项目 | 产品信息 |
| --- | --- |
| 产品名称 | 植物组织染色液（甲苯胺蓝法） |
| 货号及规格 | G4807，100 mL |
| 染料 | 甲苯胺蓝 O（Toluidine Blue O） |
| 制剂形式 | 商品化工作液，按实际染色容器所需体积取用 |
| 浓度及组成 | 说明书未列出染料浓度、溶剂或缓冲液配方及 pH，不据此反推自配配方 |
| 保存条件 | 室温、避光保存；说明书标示有效期为 1 年，具体以瓶签为准，开封后使用期限未单列 |
| 产品适用范围 | 高等植物茎、叶的石蜡切片及徒手切片染色 |

本方法采用该工作液染色 30 min。说明书的常规参考条件为常温染色 15～30 min；本实验实际染色温度仍待补充。说明书采用 3～10 μm 切片、蒸馏水短洗及 95%乙醇分化 3～5 s，本方法保留 12 μm 切片、流水清洗及 95%乙醇分化 15 s，不将二者写作完全相同的操作方案。

采用北京索莱宝科技有限公司（Solarbio）的无味中性树胶（D 型），作为本方法的中性树脂封片剂。

| 项目 | 产品信息 |
| --- | --- |
| 产品名称 | 无味中性树胶（D 型） |
| 货号及规格 | G8593，100 mL |
| 制剂特点 | 以烷烃类化合物为溶剂配制的树胶，不含二甲苯；说明书未公开具体溶剂名称及树胶配比 |
| 相容性 | 兼容二甲苯及环保组织透明脱蜡液，可用于本方法二甲苯透明后的切片 |
| 使用量参考 | 说明书建议每片滴加 2～3 滴，缓慢盖上盖玻片并轻压，避免气泡；实际单片体积需按所用滴加器具及覆盖面积记录，不将滴数直接换算为固定微升数 |
| 封固条件参考 | 说明书允许直接镜检，或置于室温通风处晾置约 1～6 h，使其充分贴敷后镜检；本方法仍以封片剂固化后成像为终点，实际完全固化时间待补充 |
| 试剂保存 | 室温保存，说明书标示有效期为 2 年，具体以瓶签为准；开封后使用期限未单列 |
| 成片保存 | 说明书建议置于室温阴凉处保存，未给出明确保存期限 |

常规使用不另配固定稀释比例。说明书仅在长期使用后试剂变黏稠时建议用透明剂适当稀释，未给定比例，不据此设置常规稀释步骤。封片用量及封固参考条件用于准备和排期时，应与本实验实际采用的条件区分。
