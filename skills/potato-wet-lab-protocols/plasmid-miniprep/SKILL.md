# 质粒小量提取

**本技能参照天根（TIANGEN）DP103《TIANprep Mini Plasmid Kit／质粒小提试剂盒（离心柱型）》说明书（版本 DP260101）编写；实际提取方法和参数须根据用户手中试剂盒对应的说明书及瓶签确认。**

给出操作、用量或排期时，开头简要说明这一参考关系。先核对实际品牌、货号和说明书版本；其他试剂盒须按其对应说明书核对流程，不直接套用 DP103 的缓冲液名称、体积和条件。

## 适用范围与输入

用于从过夜培养的大肠杆菌中小量提取质粒 DNA，采用碱裂解和 CP3 离心吸附柱，提供实验准备、操作、分支选择及周期估算。不涵盖植物基因组 DNA 提取、质粒中量或大量提取、专用去内毒素流程。

按任务需要确认：试剂盒及版本、宿主菌、质粒大小和拷贝类型、菌液体积与培养状态、样本数、下游用途、洗脱液与体积、是否使用可选 PD 去蛋白步骤及回加洗脱，以及试剂和设备是否就绪。培养条件、抗生素种类及浓度按实际宿主和载体方案确认；本说明书只要求过夜培养，未给这些参数。

## 分支选择与按需读取

DP103-02（50 次）和 DP103-03（200 次）为包装规格，单样本流程相同。完整步骤、精确用量和时间核算见 [references/protocol.md](references/protocol.md)；给出完整流程前读取该文件，单步咨询读取相关小节即可。

Hermes 调用：`skill_view(name="plasmid-miniprep", file_path="references/protocol.md")`。

| 分支 | 选择依据与处理 |
| --- | --- |
| 常规小提 | 1–5 mL 过夜培养菌液，采用 P1/P2/P3 为 250/250/350 μL 的基础流程 |
| 低拷贝或大质粒 | 低拷贝质粒或大于 10 kb 的质粒，说明书另建议 5–10 mL 菌液、按比例增加 P1/P2/P3，EB 于 65–70 °C 预热，并适当延长吸附和洗脱时间；具体放大倍数、延长时间及上柱安排须进一步核对，见参考文件 |
| PD 去蛋白，可选 | 上柱结合后加 PD；不选时直接进行第一次 PW 漂洗。说明书未限定必须使用的菌株或条件，不擅自设为必做 |
| 洗脱液选择 | 常规用 EB；后续测序时，本说明书要求用 pH 7.0–8.5 的 ddH₂O。低拷贝/大质粒且需水洗脱时，水的预热条件需按实际配套说明确认 |
| 回加洗脱，可选 | 将首次得到的 DNA 溶液回加原柱再洗脱，以提高回收量；不另加一份新洗脱液 |

说明书列出的参考得率为：1–5 mL 菌液中，低拷贝质粒 3–12 μg，高拷贝质粒 6–30 μg。实际得率与菌株、培养、裂解、拷贝数和质粒稳定性等有关；该表不代表保证产量，也不代表 CP3 柱容量上限。

## 实验前准备

给出完整流程或排期前，先提醒用户备齐材料和设备，单独列出以下准备及就绪条件；仅回答单步问题时提示相关准备即可。

| 类别 | 准备要求 |
| --- | --- |
| 材料 | 已完成过夜培养的大肠杆菌；记录样本数、各样本菌液体积、质粒大小和拷贝类型。培养及培养所需设备、培养基和抗生素提前安排 |
| 仪器 | 台式离心机及匹配柱/管的转子或适配器、移液器、计时器；P1 重悬可用移液器或涡旋振荡器。离心按室温 12,000 rpm（说明书标注约 13,400 ×g），实际转子及耗材需适配；按有效容量分批 |
| 条件性设备 | 试剂有沉淀或浑浊时备 37 °C 水浴；低拷贝/大质粒分支备 65–70 °C 水浴用于 EB 预热。选做定量或电泳时备相应检测仪器及耗材 |
| 耗材 | 每个常规单柱样本至少 1 个菌体收集兼裂解管、1 个 CP3 柱及其 2 mL 收集管、1 个干净洗脱收集管；另备吸头、管架、标签及平衡管。管规格与工作容量按菌液分次收集和裂解液体积选择；检测、分装或增柱耗材另计 |
| 试剂 | BL、已加 RNase A 的 P1、P2、P3、已按瓶签加无水乙醇的 PW、EB 或所选 ddH₂O；选择去蛋白时备 PD。单样本和整批净用量见参考文件，备用余量另列 |
| 就绪条件 | 确认 P1 的 RNase A 添加记录、保存条件及有效期，确认 PW 的乙醇添加记录；检查 BL/P2/P3 状态，准备当天平衡的柱；标记管和柱、核对转子容量及可用时段，必要的恒温设备提前达到目标温度 |

试剂盒通常在 **15–30 °C 干燥条件**下保存，单独包装的 RNase A 室温保存。首次使用前，将配套 RNase A 全部加入对应 P1，混匀后于 **2–8 °C** 保存，可稳定保存 **6 个月**。若溶液有沉淀，使用前可于 **37 °C 水浴 10 min** 复溶；尤其检查 BL、P2、P3 是否浑浊。PW 添加无水乙醇的体积查瓶签，不根据包装内原液量推算。

避免直接接触 P2/P3，用后立即盖紧。柱平衡安排在使用当天。P1 重悬可涡旋，加入 P2 后采用温和上下翻转，不能沿用涡旋方式。

## 周期估算

菌液已过夜培养、材料和设备就绪时，提取主体可当天完成；若从培养前开始，则需提前安排过夜培养，说明书未给固定培养小时数。以**开始柱平衡至收集首次 DNA 洗脱液**为计时范围，单批为不超过离心机有效容量的 `n` 个单柱样本。

常规分支按每样本一次菌体收集、一次上柱、两次 PW 漂洗、采用建议的开盖晾干、一次洗脱，且不做 PD 去蛋白或额外澄清离心时，**已明确的定时步骤小计为 21.5–26 min（约 0.36–0.43 h）**。这不等于完整提取周期：未含 P1 重悬、P2 裂解及其他移液和上下机时间；其中 **P2 裂解不超过 5 min** 是上限，不能当作固定孵育时长。

| 分支 | 定时小计的变化 |
| --- | --- |
| 增加 PD 去蛋白 | 增加 0.5–1 min；基础小计变为 22–27 min |
| 回加洗脱一次 | 增加 4 min；基础小计变为 25.5–30 min |
| PD 且回加洗脱一次 | 合计 26–31 min |
| 多次收集菌体 | 每多一轮收集离心增加 1 min，另计加样和吸除上清 |
| 额外澄清离心、分次上柱或低拷贝/大质粒调整 | 按核实后的次数与时长另计；不能直接套用基础小计 |

详细计算见参考文件。P1/PW 准备、条件性的 37 °C 复溶、EB 预热及仪器预约提前量单列。培养、人工操作、设备升降速与等待、检测、分装及入库时间另计；新增估算注明依据。按样本数、设备容量、分支和人员安排批次，共用离心时间不简单乘以样本数，也不忽略逐管操作。P2 加入至 P3 中和须逐样本控制在 5 min 内，批量移液不能使后处理样本超时。不自行增加裂解液或柱上的过夜暂停点。

## 检测与保存

说明书未规定 DNA 检测取样量、检测条件或合格阈值。用户需要时，可补充用微量紫外分光光度计检测浓度与纯度，或用琼脂糖凝胶电泳查看质粒条带；明确这些是检测安排，参数及取样量按设备、样本浓度和下游用途确定。准备对应仪器和试剂，定量时用同种洗脱液作空白。

说明书在 ddH₂O 洗脱注意事项中要求 DNA 产物于 **−20 °C** 保存，未另列 EB 洗脱产物的保存时限。其他保存安排按实际配套说明书或已确认的实验室方案执行，勿将试剂盒的室温储存条件当作 DNA 产物保存条件。
