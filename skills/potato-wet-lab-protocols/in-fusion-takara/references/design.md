# In-Fusion 载体与引物设计

本文件用于选择载体线性化位点、设计末端同源序列及检查预期重组序列。实验配液和孵育条件见 [protocol.md](protocol.md)。

## 设计所需信息

准备载体完整序列、保留骨架的范围、线性化方式、插入片段序列及目标构建图谱。多片段组装需明确各片段的排列顺序与方向；融合表达构建需明确标签、起始密码子、终止密码子和连接肽的保留要求。

## 载体线性化位点

1. **确定插入位置。** 在预定位置选择线性化位点，检查需要保留的启动子、复制起点、抗性基因及其他功能元件，避免破坏载体骨架。
2. **核对酶切图谱。** 限制性内切酶应仅产生预期切口；如存在多个识别位点，需确认所得骨架包含全部待保留序列。条件允许时可优先采用双酶切，并核对缓冲液、温度和甲基化敏感性等条件。两个识别位点不应重叠，相邻位点之间宜保留至少约 5 bp。
3. **确认实际末端。** 以线性化后保留骨架的真实末端序列设计同源区，不能直接用未切质粒图谱上的任意邻近序列替代。单酶切也可使用，但须充分去除未切环状质粒。
4. **明确连接序列。** 是否保留酶切位点取决于目标构建及引物设计；融合表达时同时检查阅读框。In-Fusion 反应不要求载体末端补平或去磷酸化，也不需另加 DNA 连接酶。

插入片段内部存在相同限制酶识别位点，通常不影响 In-Fusion 组装，因为插入片段无需使用同一限制酶处理。插入方向由两端同源序列的对应关系决定。

## 引物设计

每条引物均按 5′→3′ 方向书写，由 **5′ 端同源序列**和 **3′ 端模板特异性退火序列**组成。前者对应相邻载体或 DNA 片段的末端，后者用于扩增目标片段。

| 项目 | 设计要求 |
| --- | --- |
| 单片段组装 | 插入片段两端分别设置与相邻载体末端对应的 15 bp 同源序列 |
| 多片段组装 | 相邻片段之间的同源序列宜延长至 20 bp；按目标排列逐一检查载体与插入片段、插入片段彼此之间的连接位点 |
| 退火序列 | 按常规 PCR 引物原则设计；退火温度主要依据 3′ 端与模板互补的部分计算，不将 5′ 端附加同源序列直接计入初始模板退火区 |
| 方向与互补关系 | 分别核对正、反向引物及其扩增产物两端的序列，尤其注意反向引物的反向互补关系 |
| 融合表达 | 检查起始密码子、终止密码子、标签方向、连接肽和阅读框；需要与载体编码的 C 端标签融合时，插入序列不保留阻断融合表达的终止密码子 |
| 最终连接序列 | 确认酶切位点的保留或删除符合预期，无非预期的碱基重复、缺失或额外序列 |

可使用 [Takara 官方引物设计工具](https://www.takarabio.com/learning-centers/cloning/primer-design-and-other-tools) 辅助设计，或用 SnapGene 模拟组装。输入完整序列及实际线性化方式，并核对输出的连接序列、插入方向和阅读框。

## 设计结果检查

1. 按预期顺序拼接载体与各插入片段，确认每个连接位点的同源序列正确对应。
2. 检查最终构建中的插入序列、连接位点及需保留的功能元件；融合表达构建同时核对编码序列的连续性。
3. 输出标明同源区和特异性退火区的引物序列、预期片段长度及连接序列。缺少实际序列时，仅给出设计原则，不推定具体引物序列。
