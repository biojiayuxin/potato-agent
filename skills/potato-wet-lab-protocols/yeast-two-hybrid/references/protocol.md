# AH109 酵母双杂交操作流程

适用于 pGBKT7-X 与 pGADT7-Y 的 PEG4000 双质粒共转化。所有配液及操作用水均为 ddH2O；“无菌水”指经灭菌、冷却至室温的 ddH2O。母液、工作液和培养基配方见 [reagents.md](reagents.md)。

## 材料、仪器、耗材与试剂

### 实验前准备

1. 按技能入口的[体系适用性与融合构建设计](../SKILL.md#体系适用性与融合构建设计)检查转录调控活性、跨膜结构域及已有自激活记录，确定实际融合方向或受检片段。确认编码序列与 BD、AD 正确同框连接；测序覆盖插入片段与两端融合接头，无移码、意外突变或提前终止。终止密码子按具体融合设计处理。
2. 备好 AH109、目标质粒、空 pGBKT7、空 pGADT7、pGBKT7-53、pGADT7-T 和 pGBKT7-Lam。测定每份 DNA 浓度，使用低盐、无明显乙醇残留的质粒，对照质粒的纯度应与实验组相当。记录构建编号、浓度、测序结果和所需加样体积。
3. 提前备齐 YPDA 固体与液体、DDO 固体与液体、QDO 固体培养基及无菌水。核对 SD-base 是否含糖及 DO 补充粉的营养缺失类型，完成灭菌、冷却、倒板和表面干燥。
4. 当天无菌配制 1×TE/LiAc 和 PEG/LiAc，检查 PEG/LiAc 无沉淀且混匀。预热 30 °C、42 °C 水浴，备好冰浴；ssDNA 使用前沸水浴 5 min，立即冰浴并在使用期间置冰上，变性细节按产品要求。
5. 标记实验组、独立转化编号、菌落编号、培养基和稀释倍数，并绘制点样位置示意图。同一批次相互比较的各组使用同批感受态和培养基，培养条件保持一致，以点样后的培养时长为基准比较各组生长情况。感受态当天制备、当天使用。

实验前完成上述准备，并核对以下设备及其运行条件。

| 设备 | 使用条件与准备要求 |
| --- | --- |
| 培养箱、摇床 | 28 °C；种子液和扩大培养使用 250 rpm；核对培养瓶、克隆培养管及平板容量 |
| 水浴及冰浴 | 30 °C 孵育、42 °C 热激；另备 ssDNA 变性用沸水浴、立即冷却用冰及管架 |
| 离心机和匹配转子 | 收菌为室温 1,000 × g；转化后及调整菌液浓度前约 2,000 × g；核对收菌管与微量管适配、容量和短时离心计时方式，不将 × g 当作 rpm |
| 分光光度计及比色皿 | 检测 OD600；确认检测线性范围、最低取样体积和空白液，超量程按设备要求稀释并折算 |
| DNA 定量设备 | 检测质粒浓度，取样量按所用仪器要求另计 |
| 涡旋仪、移液器 | 能处理黏稠 PEG 工作液；覆盖 5 μL 点样、质粒加样及毫升级转移 |
| 配液和无菌操作设备 | 天平、pH 计、定容器具、灭菌设备、无菌过滤用品及超净台等无菌操作区 |
| 保存与记录设备 | 4 °C 培养基平板短期保存、−20 °C ssDNA 分装保存，以及平板拍照设备 |

### 分组与重复

| 组别 | BD 质粒 | AD 质粒 | DDO 预期 | QDO 判据或用途 |
| --- | --- | --- | --- | --- |
| 实验组 | pGBKT7-X | pGADT7-Y | 生长 | 检测待测互作 |
| 诱饵蛋白自激活对照 | pGBKT7-X | pGADT7 空载体 | 生长 | 不应持续生长；检查 X 自激活 |
| 猎物蛋白背景对照 | pGBKT7 空载体 | pGADT7-Y | 生长 | 不应持续生长；检查 Y 相关背景 |
| 双空载对照 | pGBKT7 空载体 | pGADT7 空载体 | 生长 | 不应持续生长；检查培养基选择效果及背景生长 |
| 阳性对照 | pGBKT7-53 | pGADT7-T | 生长 | 应生长 |
| 阴性对照 | pGBKT7-Lam | pGADT7-T | 生长 | 应无持续生长 |

另设不加质粒的转化空白，其余组分不变，以相同 DNA 溶剂补足对应体积；在 DDO 检查污染或选择失效，预期不出现持续生长的菌落。若需确认空白细胞存活，可另涂 YPDA，平板与培养空间另计。

建议每组至少 3 次独立转化，每次均独立配制并完成转化反应，再挑取独立 DDO 菌落复测。同一次转化挑 3 个菌落属于克隆复测，不能记为 3 次独立转化；四个稀释度、两种培养基和备用平板也不增加独立转化次数。同一感受态批次的独立转化应如实记录批次，不能声称来自不同培养批次。

### 单个蛋白对的试剂与耗材用量

令每组独立转化次数为 `r`，无质粒空白数为 `b`，总转化反应数 `R＝6r＋b`。每次双质粒转化选 1 个克隆时，复测克隆数 `c＝6r`；多挑克隆时另行增加 `c`。以下示例取 `r＝3、b＝1、R＝19、c＝18`。

| 转化试剂 | 每反应理论用量 | 六组各 3 次，不含空白（18 管） | 加 1 管空白的理论用量（19 管） |
| --- | --- | --- | --- |
| 新鲜感受态 | 100 μL | 1.8 mL | 1.9 mL |
| ssDNA，10 mg/mL | 10 μL（100 μg） | 180 μL | 190 μL |
| PEG/LiAc | 600 μL | 10.8 mL | 11.4 mL |
| DMSO | 70 μL，孵育后加入 | 1.26 mL | 1.33 mL |
| BD、AD 质粒 | 各 0.10 μg；空白不加 | 两类质粒合计 3.6 μg | 同为 3.6 μg，空白另备匹配溶剂 |
| 转化后重悬用无菌水 | 1 mL | 18 mL | 19 mL |

19 管示例中，各质粒净质量分别为：BD-X、AD-Y、空 BD、空 AD、pGADT7-T 各 **0.60 μg**；pGBKT7-53、pGBKT7-Lam 各 **0.30 μg**。质粒加样体积为 `0.10 μg ÷ 浓度（μg/μL）`；若浓度使用 ng/μL，则为 `100 ng ÷ 浓度`。检测取样及损耗另计，不改变每管 DNA 质量。

一次感受态制备加入 YPDA 的净量为 `1＋10＋100＝111 mL`；洗菌无菌水 **50 mL**；1×TE/LiAc **3 mL**；所得感受态约 **3 mL**。按实际可回收体积决定能供多少反应，理论上可供 30 管转化使用，该数量未计移液损耗；不足时另制备同规格批次，不通过额外加水或缓冲液稀释细胞凑足管数。

克隆培养以每克隆 3 mL 液体 DDO 为用量计算示例，18 个克隆共 **54 mL**。每克隆三步十倍稀释需要无菌水 **2.7 mL**，18 个共 **48.6 mL**。19 管示例中，已确定的无菌水理论用量为 `50＋19＋48.6＝117.6 mL`，尚须另加调整菌液浓度时的洗涤、重悬、OD 测定空白参比及其他实际用水。

各转化子调整浓度后的 OD600＝1.0 菌液，至少需 **110 μL** 用于首级稀释（100 μL）和两种平板上的未稀释菌液点样（各 5 μL），另加 OD 检测取样和移液损耗；洗涤及调整菌液浓度时的总体积按实际菌量和仪器要求确定，不以 110 μL 作为规定重悬体积。

| 耗材 | 理论用量与核算依据 |
| --- | --- |
| 透气培养容器 | 种子培养、扩大培养各 1 个，实际培养液约 11、101 mL，留足通气空间；克隆培养容器 `c` 个，示例每个装 3 mL |
| 收菌离心管 | 2 支，每支容纳约 50 mL 菌液；核对接种新增体积、实际工作容量及转子，不超装 |
| 转化微量管 | `R` 支，建议用 2 mL 无菌管，以容纳反应液、混匀及随后 1 mL 重悬 |
| 转化子收集及菌液浓度调整用管 | 至少 `c` 支，可在同管完成收集、洗涤及重悬；单次处理量须符合工作容量 |
| 稀释管 | 每克隆 3 支，各容纳 1 mL 稀释液，即 `3c` 支；示例 54 支 |
| YPDA 平板 | 复苏用 1 个；已有合适新鲜菌落可省去；空白活性检查选做时另加 |
| DDO 初筛平板 | 按每管转化液涂布 200 μL 计算，用 `R` 个；示例 19 个；回收剩余菌液的额外平板另计 |
| DDO 纯化平板 | 示例每克隆独立划线用 1 个，共 `c` 个；采用经确认的分区划线时按分区数量重新计算，并避免区域间交叉污染 |
| DDO/QDO 点样平板 | 每个转化子在每种培养基上点 4 个浓度梯度；先安排实验组及相应对照的点样位置，再按每板行数计算。同一对照需在多对平板重复点样时，将新增行数计入平板需求 |
| 无菌涂布工具、接种环和吸头 | 按实际涂板、挑克隆、逐级稀释、加样及点样次数准备；每步稀释换吸头，每个点使用独立无菌吸头 |
| 比色皿、试剂分装及配液容器 | 按仪器要求、检测次数和分装方案计数，另留备用 |

若每个平板可排 6 行，每一对 DDO/QDO 放齐六组的一个重复，则 18 个转化子需要 3 对点样平板。按上述每个转化子单独划线纯化的示例，DDO 理论用量为 `19＋18＋3＝40` 个，QDO **3** 个，复苏用 YPDA **1** 个；已有合适的新鲜 AH109 菌落时，不计复苏平板。这是点样布局及用量计算示例，实际平板容量应根据平板规格确定。

以上均为理论用量，另按实验室的移液损耗、死体积及备用板计划留量并说明依据。例如可配 **20 mL PEG/LiAc** 供 19 管净用 11.4 mL，剩余 8.6 mL 是该配液规格下的储备，不是额外实验组。培养基用量按实际平板数与每皿培养基体积计算，再单列倒板损耗；配制余量须注明计算依据。

### 多个蛋白组合的设计与分批

1. 逐一列出每个实验组和相应对照的 BD、AD 质粒。仅当质粒组成完全相同、使用同批感受态且实验条件一致时，才可共用同一对照；不同诱饵构建分别设置自激活对照，不同猎物构建分别设置背景对照。不同批次均须有相应对照，不能用另一批次的对照替代。
2. 同一诱饵 X 与 `n` 个猎物蛋白分别配对时，同批共有 `n` 个实验组、`n` 个猎物背景对照，以及诱饵自激活、双空载体、阳性和阴性对照各 1 组，即 `G＝2n＋4` 种不同质粒组合。每种组合转化 `r` 次，则双质粒反应数为 `Gr`；另加各批无质粒对照。每份质粒按其在实际反应中出现的次数计算用量，不能按质粒种类平均分配总 DNA 量。
3. 根据感受态实际可用体积、水浴和离心机容量及操作人员的处理能力安排批次。可将全部组合各完成一次转化作为一个重复，将若干完整重复安排在同批；每批保留相应对照及无质粒对照。硬件可容纳的管数仅为容量上限，实际操作还须满足各管混匀、孵育、热激和冷却的计时要求。

例如，X 与 Y1、Y2、Y3 分别配对，10 种组合各做 3 次独立转化，共 30 管双质粒反应。在水浴、微量离心机均可容纳 24 管，每批另设 1 管无质粒对照的条件下，可先按两批进行容量核算：第一批包含全部 10 种组合的两个重复，第二批包含全部组合的第三个重复。

| 项目 | 第一批：20＋1 管 | 第二批：10＋1 管 | 合计 |
| --- | --- | --- | --- |
| 感受态理论用量 | 2.1 mL | 1.1 mL | 3.2 mL |
| ssDNA，10 mg/mL | 210 μL | 110 μL | 320 μL |
| PEG/LiAc | 12.6 mL | 6.6 mL | 19.2 mL |
| DMSO | 1.47 mL | 0.77 mL | 2.24 mL |
| 转化后重悬用无菌水 | 21 mL | 11 mL | 32 mL |
| 两类质粒总质量 | 4.0 μg | 2.0 μg | 6.0 μg |

按每次约 3 mL 的感受态制备规模，至少需制备两份，不能将一份 3 mL 悬液稀释至 3.2 mL。两份制备合计需液体 YPDA **222 mL**、收菌后水洗用无菌水 **100 mL**、1×TE/LiAc **6 mL**，损耗另计；制备日期与转化日期相对应。PEG/LiAc 可在两批转化当天分别配制 20 mL 和 10 mL，其中配制余量分别为 7.4 mL 和 3.4 mL。其余试剂及耗材也须分别列明理论用量和备用量；没有实测损耗时，可采用注明依据的预算假设，不将该假设写成方法规定。

上述两批方案尚须结合操作人数确认可执行性。若实际处理能力不足，需要增加批次，应同步重算各批对照、感受态制备次数和总用量。仅为控制单管计时而将同批反应分段操作时，明确分段安排；若用户要求每个操作批均设无质粒对照，则按实际操作批数增加，不能遗漏。

多个组合共用对照时，还须核算对照的重复点样量。例如每对 DDO/QDO 平板排 6 行，分别放置一个蛋白对的完整六组，每个重复需要 3 对平板，3 个重复共需 **9 对**。虽只有 30 个不同转化子，但同一对照需在不同平板重复点样；不能仅用 `向上取整(30/6)` 估算每种平板数量。此布局下 DDO 共需 `32＋30＋9＝71` 个，QDO **9** 个，未含备用平板。

重复点样不增加独立转化次数。同一菌液需点于 `p` 对平板时，OD600＝1.0 菌液用于首级稀释和未稀释点样的最低体积为 `100＋10p μL`，还须加上 OD 测定取样及移液损耗；各级稀释液也应按实际点样次数检查是否足量。

## 操作步骤

### 1. AH109 复苏与液体培养

1. 从 AH109 保存菌取少量菌液，在 YPDA 固体培养基划线，**28 °C 培养 2–4 天**，选新鲜、独立、形态正常、直径约 **2–3 mm** 的菌落。已有符合条件的菌落时从下一步开始。
2. 将一个新鲜菌落重悬于 **1 mL YPDA**，转入装有 **10 mL YPDA** 的透气培养瓶，**28 °C、250 rpm** 培养至 **OD600＝1.4–1.8**。
3. 取 **1 mL** 种子液接种至 **100 mL YPDA**，同样以 **28 °C、250 rpm** 培养至 **OD600＝0.6–0.8**。使用通气空间充足的培养瓶，以 OD 达标决定收菌时间。

### 2. 收菌与制备感受态

1. 将菌液分装为两份，每管约 **50 mL**，按实际体积核对收菌管工作容量。室温 **1,000 × g 离心 5 min**，弃上清，保留沉淀。
2. 每管用 **25 mL 无菌水**轻轻重悬；再以室温 **1,000 × g 离心 5 min**，弃上清，保留沉淀。
3. 每管分别用 **1.5 mL 新鲜 1×TE/LiAc** 重悬，共约 **3 mL** 感受态悬液。轻柔混匀后按每反应 **100 μL** 分配，当天使用。

### 3. 双质粒共转化与 DDO 初筛

1. 在各转化管中依次加入 **10 μL ssDNA（10 mg/mL）→0.10 μg BD 质粒→0.10 μg AD 质粒→100 μL 感受态→600 μL PEG/LiAc**，涡旋混匀 **1 min**。空白保留其余组分，用同种 DNA 溶剂补足相应体积。
2. **30 °C 水浴孵育 30 min**。每管加入 **70 μL DMSO**，轻柔颠倒混匀，再于 **42 °C 水浴热激 15 min**。DMSO 在 30 °C 孵育后加入；反应体积此时为 **780 μL＋两种质粒体积**，不要把工作液浓度写成最终反应浓度。
3. 立即冰上冷却 **2 min**；室温 **2,000 × g 离心 10 s**。确认菌体已沉降后小心弃上清，保留沉淀。若没有可靠沉淀，先按实际设备确认适合的离心条件并记录，不能直接吸走悬浮细胞；条件调整须同步更新计时。
4. 每管加入 **1 mL 无菌水**，轻柔重悬；取 **200 μL** 涂一块 DDO 平板，**28 °C 倒置培养 2–4 天**。如需提高低效率样本回收率，可将剩余菌液分摊至额外 DDO 平板；每组记录实际铺板体积，增加涂布耗材与操作时间。
5. 记录各组菌落数或分布密度、出现时间与菌落大小。各双质粒组合均应获得 DDO 菌落，无质粒对照应无持续生长。若某组不生长，先排查 DNA、标记、菌株状态、转化条件和构建毒性，不能据此判定两种蛋白不存在互作。确认有独立 DDO 菌落后进入下一阶段。

双质粒共转化涉及质粒质量比及表达负担等因素，不把单质粒转化效率公式或菌落数直接用于解释互作强弱。

### 4. 单菌落纯化与梯度稀释点样

1. 从各次独立转化的 DDO 平板挑取分离良好的菌落，在新鲜 DDO 平板划线纯化。培养温度沿用 **28 °C**，以获得可挑取的独立菌落为终点；具体耗时按实际生长记录另计。
2. 每个经划线纯化的转化子接种少量液体 DDO，用量计算示例为 **3 mL/克隆**，**28 °C 振荡培养**至菌量满足浓度调整及后续点样需要；各组应选择生长状态相近的菌液进行比较。此阶段未指定振荡转速，执行前按培养容器与实验室已验证条件补充，不直接套用扩大培养时的转速。记录与空载对照相比的生长差异。
3. 收集适量菌液，室温约 **2,000 × g 离心 2 min**，弃去培养基上清，保留沉淀，用无菌水轻柔重悬。若需进一步去除残留培养基，则将该水悬液按相同条件再次离心 **2 min**，弃上清后重新用无菌水重悬，即增加一次水洗；记录是否选择该步骤。未选择额外水洗时，不再离心，直接进行下一步。
4. 以无菌水为空白参比，将各转化子菌液调至 **OD600＝1.0**。取样量及菌液总体积按仪器、菌量、稀释和点样需求确定。
5. 每克隆另取 3 支稀释管，各预装 **900 μL 无菌水**。取 **100 μL** 经浓度调整的菌液加入第一管、充分混匀；再依次取上一级 **100 μL** 加入下一管。每步更换吸头，得到 OD600 约 **1、0.1、0.01、0.001** 4 个浓度梯度。
6. 从各浓度梯度的菌液中分别取 **5 μL**，点接于 DDO 和 QDO 平板；每个转化子单独占一行，两种培养基的点样位置相互对应，并包含相应对照。待菌液被平板吸收后倒置，**28 °C 培养 2–4 天**。
7. 建议每日拍照，在相同培养时长下比较各组生长情况。观察点样区域内菌落的增殖及不同稀释度下的持续生长情况，避免将点样时残留的菌体误判为增殖。

### 5. 对照检查与结果判定

| DDO 生长情况 | QDO 生长情况 | 结果解释与后续处理 |
| --- | --- | --- |
| 实验组及对照均正常生长 | 阳性对照生长；阴性及三种空载体对照均无持续生长；实验组在独立重复中均生长 | 支持 X、Y 在酵母体系内互作；保存各次独立转化的复测图像，并根据蛋白来源，在目标生物或适当体系中进一步验证 |
| 实验组生长 | 实验组不生长；阳性对照生长，阴性与空载体对照均无持续生长 | 当前条件下未检测到互作，不排除其他条件下的互作 |
| 实验组生长 | BD-X＋AD 空载体也生长 | 诱饵自激活，实验组可能是假阳性，不能据此作互作结论 |
| 实验组生长 | BD 空载体＋AD-Y 也生长 | 猎物相关背景或非特异激活，可能造成实验组假阳性 |
| 实验组不生长或生长明显受抑 | 无论 QDO 生长情况如何 | 先排查转化失败、构建错误或融合蛋白表达产生的毒性，暂不判定互作结果 |
| 阳性对照在 DDO 生长 | 阳性对照在 QDO 上不生长，或阴性／双空载在 QDO 持续生长 | 本批次对照结果不符合预期，应查明原因后重新试验，暂不判定实验组结果 |

阳性结果应同时满足 DDO 生长正常、实验组在 QDO 可重复持续生长、匹配空载及阴性对照无相同表型、阳性对照在 QDO 上生长。应结合上述各对照的生长结果进行综合判定，不仅依据未稀释菌液的点样结果、单张照片或一次转化结果得出结论。

## 常见问题

| 现象 | 优先排查 |
| --- | --- |
| 所有组 DDO 无菌落 | 是否误用 QDO；菌株活性、对照质粒、PEG 适用等级、ssDNA、缓冲液配比、热激温度及 DNA 的盐或乙醇残留 |
| 某构建菌落小或出现晚 | DNA 质量；将菌液调整至相同 OD600 后复测其在 DDO 上的生长情况，检查融合蛋白表达，评估构建毒性 |
| 空载体对照在 QDO 上生长 | 营养缺陷型培养基的组成、交叉污染；从新鲜 DDO 克隆复测。具有转录激活活性的诱饵应重点检查自激活；调整诱饵片段或融合方向后，重新设置匹配对照并复测 |
| 仅未稀释菌液的点样区域出现疑似生长 | 残留培养基成分及点样菌体；结合培养过程中的增殖和较高稀释度的生长情况判断 |
| 重复不一致 | 初始 OD、细胞状态、点样体积、培养基批次、实际培养时长及独立转化记录 |
| 实验组在 QDO 上不生长，但对照结果符合预期 | 按当前条件下未检出记录；检查融合蛋白表达、核定位、融合后结构域的可及性及四缺培养条件对弱互作信号检出的影响。若待测蛋白具有转录抑制功能，还需考虑报告基因表达受抑的可能性，必要时采用不依赖转录激活的方法验证 |

## 记录与保存

记录构建与测序编号、DNA 浓度、感受态和培养基批次、独立转化与克隆对应关系、实际铺板体积、OD、洗涤次数、稀释度、点样量、培养起止时间和结果。保存点样位置示意图及相同培养时长下的 DDO/QDO 平板照片；追加表达检测或其他互作验证时，另列所用方法与周期。

配好的培养基平板密封、4 °C 短期保存，避免失水和反复升温；ssDNA 分装 −20 °C 保存，使用期间置冰上。感受态当天使用。菌株或转化子的长期保存条件未给出，需采用实验室已验证方案；不把培养基平板的保存要求当作菌株长期保存方法。

## 实验周期与已明确时长的步骤

起点为质粒、试剂及设备准备完毕后开始 AH109 复苏，终点为全部独立转化子在 DDO/QDO 上的生长观察与结果记录完成。以下以六组各 3 次独立转化、另设 1 管无质粒对照（`R＝19`），每次双质粒转化选 1 个菌落（`c＝18`）为例，核对各步骤已经明确的耗时。这些步骤分布于不同实验阶段，不能将其小计作为单人连续完成实验的时间。

| 阶段 | 已知时长 | 计算与未定时部分 |
| --- | --- | --- |
| 实验前准备 | ssDNA 沸水浴 **5 min** | 立即冰浴；其冷却、配液、灭菌升降温、倒板干燥、水浴预热及预约等待另计，不给未经确认的固定提前量 |
| AH109 复苏 | **2–4 天** | 已有合适新鲜菌落时省去 |
| 种子液培养 | 未固定 | 培养至 OD600＝1.4–1.8，记为 `T种子` |
| 扩大培养 | 未固定 | 培养至 OD600＝0.6–0.8，记为 `T扩培` |
| 收菌和水洗离心 | **2×5＝10 min** | 两支收菌管同批；转移和重悬另计 |
| 转化涡旋混匀 | **R×1 min** | 按单人逐管操作计，19 管为 19 min |
| 转化孵育、热激、冰浴 | **30＋15＋2＝47 min/操作批** | 能同时处理时仅计一次；分批操作按实际计时安排计算，加 DMSO 和转移另计 |
| 转化后离心 | **10 s/批** | 以实际沉降和设备计时为准；加减速及条件调整另计 |
| DDO 初筛培养 | **2–4 天** | 涂布及菌落记录另计 |
| DDO 划线纯化 | 未固定 | 获得可挑取独立菌落，记为 `T纯化` |
| 液体 DDO 转化子培养 | 未固定 | 获得足够用于调整菌液浓度和点样的细胞，记为 `T克隆` |
| 调整菌液浓度前的收菌离心 | **2 min/批** | 弃培养基后以无菌水重悬；选做一次额外水洗时，再加 2 min/批离心；重悬与测 OD 另计 |
| DDO/QDO 点样后培养 | **2–4 天** | 两类板同时培养，培养时间仅计算一次；吸收、稀释和点样另计 |
| 检测、记录与保存处理 | 未固定 | 质粒浓度、OD 检测、每日拍照、结果核对及保存按实际工作量另计 |

已给定平板培养小计：`(2–4)＋(2–4)＋(2–4)＝6–12 天`。起始已有合适新鲜菌落时减去复苏，得到 **4–8 天**；已有纯化转化子时，已知平板培养只剩点样后的 **2–4 天**。

按一次感受态制备、转化和菌液浓度调整均不分批、无额外洗涤计算，已明确时长的操作合计为：`10＋R＋30＋15＋2＋10/60＋2 min`。`R＝19` 时为 **78 min 10 s**；额外离心并水洗重悬一次则为 **80 min 10 s**。该计算用于逐项核对，不表明 19 管可以由一人在相同时间开始和结束处理。ssDNA 变性 5 min 单列为当天准备，其余移液、转移和设备加减速时间另计。

单人逐管涡旋 1 min 时，19 管的首末管混匀完成时间至少相差 18 min。不能默认在全部混匀后统一入浴，而忽略各管加入 PEG/LiAc 后的额外等待；本方法未给出该等待时间的允许范围。应根据已有的批量操作记录确定小批规模，或对各管分别计时、错开开始时间，并核对 30 °C 孵育结束、DMSO 加入、42 °C 热激结束、冰浴及离心是否发生操作冲突。每管均须满足规定时长，不能为等待其他样本而延长孵育或热激时间。没有可行的单人操作安排时，应减少同时处理的管数或增加操作人员，并重新核算批次。

分批时，设感受态制备分为 `M` 批，转化分为 `B` 个操作批，转化后离心共 `C` 批，菌液浓度调整前离心共 `S` 批，则已明确时长的步骤合计为 `10M＋R＋47B＋C/6＋2S min`，其中收菌按每批两次各 5 min 离心计算；增加洗涤时另加相应离心时间。该式为步骤耗时总和，批次交错进行时应按实际开始、结束时间计算日历耗时，不能再次将重叠时间全部累加。

因此，从保存菌开始的完整周期应写为：**6–12 天＋T种子＋T扩培＋T纯化＋T克隆＋已明确时长的操作＋其他人工操作、检测和等待时间**。没有后四个培养阶段的实测时长时，不承诺固定总天数。

独立转化及克隆可在容量允许时并行，3 次独立转化不必串行等待三轮培养；若安排分日重复，则按各批开始时间及实际依赖重算。涡旋按逐管操作计，水浴和离心按设备批次计；18 个克隆的移液、稀释、测 OD、涂板及每日结果观察工作量仍需计入。

选做剩余转化液的额外 DDO 铺板或无质粒对照的 YPDA 活性检查时，增加耗材和人工时间；可以同时培养时，不另加培养时间。各培养阶段均以 OD 或菌落状态达到要求为完成标准，不为凑足过夜时间而延长已达到目标 OD 的培养阶段，也不增加未经确认的低温暂停步骤。菌株冻存、构建调整及其他验证均不包含在上述周期内。

用户给出开始日期和完成期限时，应按“培养基准备→AH109 复苏→种子液培养→扩大培养→感受态制备及转化→DDO 初筛→划线纯化→转化子液体培养→菌液浓度调整及点样→生长观察”的先后关系安排。YPDA 须在复苏前备好；DDO、QDO 可在前期培养期间配制，但需确认人员和设备可用。配液时间若已与培养时间重叠，不重复相加。从保存菌开始，已知平板培养需 6–12 天；即使各阶段均按 2 天计算，10 天期限也仅余 4 天用于其余培养和操作，因此缺少实测培养记录时不能保证按期完成。
