# 染料法实时荧光定量 PCR（AQ601）

**本技能参考全式金 PerfectStart® Green qPCR SuperMix（AQ601）试剂说明书编写，仅供用户参考。用户应依据实际使用的 qPCR 试剂盒、配套说明书及仪器要求确定反应体系和操作流程。** 本技能所录参数对应 Version 2.0（V2-202301），不将其称为最新版说明书。

向用户提供实验流程、反应体系或排期时，开头应简要说明上述参考用途及适用条件；明确区分说明书参数、实验设计建议和时间估算假设。

## 适用范围与输入

用于 AQ601 染料法实时荧光定量 PCR 的实验准备、排板设计、试剂用量核算、两步法或三步法选择、荧光采集设置及排期。反应采用 SYBR Green I 检测双链 DNA。以 cDNA 为模板时，反转录须提前完成；本试剂不承担 RNA 反转录。不涵盖探针法、多重检测或完整的定量数据统计分析。

按任务需要确认以下信息，已有明确条件直接采用：

- 试剂商品名、货号、说明书版本，以及仪器完整型号、反应模块和软件设置。
- 模板类型、浓度或拷贝数、每孔投入量及体积；cDNA 另记录稀释倍数及反转录来源，不将 RNA 投入量等同于 cDNA 实测质量。
- 引物序列或已验证条件、储液浓度、目标片段及拟采用的两步法或三步法；三步法需确定 50–60 °C 范围内的实际退火温度。
- 各独立样本的编号、处理组与生物学重复编号；检测目的、目标基因及内参基因、引物对、技术重复数、无模板对照（NTC）及其他对照数。
- 单孔体积、仪器有效容量和可用时段；排板时另确认单道或多道移液方式、固定或不可用孔位及内参是否按目标分别设置。

说明书以 **20 μL/孔** 为示例。其他体积须先核对试剂及仪器适用范围，再按终浓度换算并标明“换算体系”；不按体积同比缩放循环数、温度或保温时间。用户使用其他试剂盒时，本技能仅供方案结构参考，精确参数以对应产品说明书为依据。

说明书建议以三步法提高扩增效率、以两步法提高特异性；具体选择结合引物与模板的既有验证结果。三步法在退火或延伸阶段选择荧光采集步骤，两步法在 60 °C 阶段采集。均在扩增结束后进行熔解曲线分析。

**参比染料需求与采集时间分别核对。** 需要参比染料的仪器，每 20 μL 反应加入 0.4 μL 配套的 50× Universal Passive Reference Dye；不需要时省略该组分，并相应增加补水量。仪器清单不能替代具体反应模块和软件要求。

## 排板设计

默认按 **96 孔板（A–H 行、1–12 列）** 规划，每个“独立样本 × 检测基因”设 **3 个技术重复孔**；实际规格及已确认的重复方案优先。生物学重复分别编号，技术重复不增加生物学样本量。排板规则属于补充的实验设计建议，不是 AQ601 说明书参数。

基因表达相对定量时，分别安排目标基因和内参反应。ACTIN、TUBULIN、UBI 等作为候选内参，依据材料与处理条件下的表达稳定性选用；内参引物与目标引物分孔使用。默认同一板上、同一份 cDNA 在适用且一致的实验条件下共享内参结果，也支持按用户要求为各目标分别设置内参。绝对定量等用途按自身标准品和对照方案安排，不强制套用内参规则。

排板前明确样本及引物清单，按引物体系和实际板数预留 NTC 等对照。先完成孔位分配及完整性核对，再按最终逐孔清单计算试剂、模板和上机批次；跨板新增的内参、NTC 或板间校准反应均须计入。技术重复不拆板，分板时优先保留目标与对应内参同板，避免处理组与板次完全重合。

完整排板任务输出板图、逐孔清单、试剂与模板需求及批次汇总，并说明孔位冲突、重复完整性、内参对应关系和各板对照的核对结果。仅查询板数或某一排布规则时，回答相关内容即可。

## 实验前准备

给出完整流程或排期前，先提醒用户备齐下列材料与设备，并单独核对就绪条件；仅查询配方或单个步骤时，提示与该问题相关的准备事项即可。

| 类别 | 准备要求 |
| --- | --- |
| 材料 | 已完成提取及所需质量检查的 DNA，或已完成反转录的 cDNA；明确每孔模板体积、各独立样本及处理组、目标和内参引物、重复和对照孔位，核对跨板累计的模板需求 |
| 仪器 | 具备 SYBR Green I 检测及熔解曲线功能的实时荧光定量 PCR 仪；适宜量程的校准移液器、与反应耗材匹配的离心设备及适配器；核对单批有效容量与预约时段 |
| 耗材 | 与仪器匹配、适用于 20 μL 工作体积的光学反应管、八连管或反应板及光学盖/封膜；无核酸酶滤芯吸头、配液管、稀释管和管架；每个实验反应及对照各占 1 管或孔 |
| 试剂 | AQ601 的 2× 预混液、正反向引物、无核酸酶水；按机型准备配套参比染料；各孔模板及公共混合液分别核算，移液余量另列 |
| 就绪条件 | 核对瓶签、有效期和保存状态，试剂充分解冻并混匀；完成模板和引物的必要稀释、孔位标记、检测通道及参比设置、温度程序和熔解曲线设置 |
| 操作环境 | 配液区与扩增产物处理区分开，使用洁净耗材，避免模板和扩增产物交叉污染 |

NTC 以等体积无核酸酶水替代模板，其他组分保持一致；排板默认每板每种引物体系设置 3 个 NTC 孔，可按已确认方案调整。按实验目的设置阳性对照、标准品或对应的无反转录酶（No RT）对照，分别明确孔数。这些对照及重复安排属于实验设计建议，不作为说明书规定的固定数量。不同引物对分别配制公共混合液。

## 周期估算

以材料、试剂和仪器均已就绪后开始配液为起点，以扩增、熔解曲线采集及初步结果检查完成为终点。单批为同一程序下不超过仪器有效容量的 `R` 个反应，包含重复及对照。主体流程无规定的过夜步骤。

| 程序分支 | 40–45 个循环的已知保温小计 |
| --- | --- |
| 三步法，采集步骤无需延长 | 20 min 30 s–23 min（约 0.34–0.38 h） |
| 两步法，采集步骤无需延长 | 23 min 50 s–26 min 45 s（约 0.40–0.45 h） |

以上仅包括 94 °C 预变性和循环内保温，**不等于完整实验周期**。部分 ABI 仪器需延长荧光采集所在步骤，应先调整该步骤并重算小计，见流程文件。完整周期还包括人工配液、混匀与离心、上机设置、升降温、熔解曲线运行及结果检查。

说明书未给出这些附加阶段的统一时长，因此不承诺固定的总小时数。排期时优先采用仪器显示的完整程序时间，再加实际孔数对应的人工操作时间；仪器已计入的升降温和熔解曲线不重复相加。排板核对、模板提取、反转录、试剂解冻、工作液配制及仪器预约等待作为实验前准备另计。按最终板图、程序分组和设备数量安排批次；每板新增的内参和对照会改变孔数及配液量，不能仅以初始孔数除以 96 确定板数，也不将整批运行时间直接乘以孔数。

## 检测与保存

利用仪器在反应孔内采集的扩增曲线、Cq/Ct 值及熔解曲线进行初步检查，无需另取样。结合 NTC、重复孔及所设对照评价扩增结果；出现多峰、异常曲线或 NTC 扩增时，先核查特异性与污染，再开展定量解释。不自行设定说明书未给出的通用 Ct 截止值或合格阈值。

保存原始荧光数据、孔位表、实际程序、分析设置及试剂批号。**试剂盒在 −18 °C 及以下避光保存，说明书标示保存期为两年，实际使用仍核对瓶签有效期。** 该条件不等同于配好的反应液或扩增产物的保存条件；说明书未提供后二者的保存时限，不据此设置中途或过夜暂停点。
