# ClonExpress II 载体与引物设计

适用于 Vazyme C112。用于选择载体线性化位点、设计末端同源序列及检查预期重组序列；反应配制和孵育条件见 [protocol.md](protocol.md)。

## 设计所需信息

准备载体完整序列、保留骨架的范围、线性化方式、插入片段序列及预期构建图谱。融合表达构建需明确标签、起始密码子、终止密码子和连接肽的保留要求。

## 载体线性化位点

1. **确定插入位置。** 检查需保留的启动子、复制起点、抗性基因及其他功能元件。尽量选择无重复序列、克隆位点上下游 20 bp 区域内 GC 含量为 40%–60% 的位置。
2. **选择线性化方式。** 可采用限制性内切酶消化或反向 PCR。酶切法优先选用双酶切；使用单酶切时须确保消化充分，减少未切环状质粒残留。反向 PCR 宜采用高保真聚合酶，并注意扩增模板残留。
3. **核对实际末端。** 根据线性化后保留骨架的真实末端序列设计同源区，分别检查插入片段与载体两端的对应关系。插入方向由两端同源序列决定。
4. **确定连接序列。** 按目标构建决定是否保留酶切位点；融合表达时同时检查阅读框。重组体系不依赖 DNA 连接酶，线性化载体无需进行末端去磷酸化。

插入片段内部存在相同限制酶识别位点，通常不影响该重组方法，因为插入片段无需使用同一限制酶处理。各类 DNA 的纯化或直接用样条件见流程文件。

## 引物设计

每条引物均按 5′→3′ 方向书写，依次由**载体末端同源序列、按需保留的酶切位点和基因特异性退火序列**组成。反向引物需按反向互补关系确定序列。

| 项目 | 设计要求 |
| --- | --- |
| 同源序列长度 | 15–20 bp，不将酶切位点及酶切残留碱基计入该长度 |
| 同源区组成 | GC 含量以 40%–60% 为宜，避免重复序列，并检查两端的对应关系 |
| 特异性退火区 | 按常规 PCR 引物原则设计，Tm 以 60–65 °C 为宜；此范围为引物设计指标，不直接作为统一的 PCR 退火温度 |
| 退火温度计算 | 仅依据基因特异性序列计算 Tm，5′ 端附加的同源序列和酶切位点不参与计算 |
| 引物合成 | 最终引物长度超过 40 bp 时，推荐采用 PAGE 纯化 |
| 融合表达 | 检查起始和终止密码子、标签方向、连接肽及阅读框；与载体编码的 C 端标签融合时，插入序列不保留阻断融合表达的终止密码子 |
| 最终连接序列 | 确认酶切位点的保留或删除符合预期，无非预期的碱基重复、缺失或额外序列 |

可使用诺唯赞 CE Design 辅助设计，软件获取途径见[诺唯赞官网](https://www.vazyme.com)。也可用序列分析软件核对预期重组质粒；输入实际线性化方式，检查插入方向及全部连接序列。

## 设计结果检查

1. 按预期方向拼接载体与插入片段，逐一确认两个连接位点的同源序列。
2. 检查插入序列及需要保留的功能元件；融合表达构建同时核对编码序列的连续性。
3. 输出标明同源区、可选酶切位点及特异性退火区的引物序列，并列出预期片段长度和连接序列。缺少实际序列时，仅给出设计原则，不推定具体引物序列。
